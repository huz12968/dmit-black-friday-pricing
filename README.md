## 历年黑五给过什么：三个活动加一个限量款

DMIT 黑五这些年变化不大，摸清套路，今年活动一上线你就能自己判断值不值得等。

**Pro 系列买二送一**。活动期间任选两台 Pro 系列下单，额外送一台 Pro。规格不同时送的是价格较低那台，赠品只在第一个计费周期免费，之后续费要正常付款。这个活动适合本来就要部署多台的人，比如多地区节点、主备双线；只买一台的话跟你没关系。

**消费返现**。满 $100 返 $10、满 $500 返 $100、满 $1000 返 $300，折算下来最多 30%，返的是账户余额。

**Tier 1 STARTER 高比例返现**。购买不低于季付的 T1 STARTER，三个月后返还余额：香港机房返 70%，圣何塞机房返 50%。换算过来，香港 T1 STARTER 季付的实际成本是原价的三成，是历年黑五力度最大的一档。

**限量特价套餐**。过去放过 2核 / 2G / 40G SSD / 1000G 月流量、$139/年 的洛杉矶套餐，不用优惠码直接是这个价。这类货通常开抢后几小时内售罄。

限制也得一起说清楚：返现要等三个月到账，返的是账户余额，不能提现，退款时会扣除；买二送一的赠品续费不免费；黑五活动一般不能和常设优惠码叠加；活动有效期通常 5 到 7 天，但限量货往往提前就没了。

按这些规则算，如果你是只买一台自用的人，往年黑五给你的实际优惠是多少？消费返现要满 $100 才返 $10，等于 10%；常设码给 EB 系列的是 20%，给香港东京 T1 的是 30%。买二送一对单台购买者等于零。真正值得等黑五的只有两类：本来就要买两台以上 Pro 的，和抢得到限量特价款的。

## 常见问题

**DMIT 黑五每年都有吗？** 从公开记录看，2019、2020、2022、2023 年都有活动，买二送一和消费返现是固定保留节目，形式略有差异。

**黑五活动能和常设优惠码一起用吗？** 一般不行。活动期间通常注明不可与其他折扣叠加，常设码留到非活动期用更合适。

**限量套餐多久卖完？** 快的时候几小时内。活动有效期标称 5 到 7 天，货没了就提前结束。

**现在买还是等？** 只买一台的话，现在用常设码拿 20% 到 30% 的循环折扣，比赌一个未公布力度的活动稳。要买两台以上 Pro，等买二送一。

**支持哪些付款方式？** 支付宝、微信、PayPal。

**优惠码填在哪一步？** 购物车的 Apply Promo Code 输入框，填完点 Validate Code 验证通过再付款。
